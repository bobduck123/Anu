## Strategic Adjustment - 2026-08-09

Updated competitive posture: a Myspace relaunch is not a confirmed immediate execution threat, but it is a high strategic/category threat if Viant combines Myspace nostalgia, AI-generated expressive profiles and free or cheap ad-subsidised pricing.

Presence must defend as premium owned cultural worlds, not as cheap custom profiles, link-in-bio pages or AI site generation. Gate 4 references now count toward app execution only when they produce app-compatible registry primitives or a clear adaptation path into owner-editable, persistence-aware and public-safe Presence runtime.

Standalone reference polish is still allowed when it makes primitives trustworthy, but it must not serialize the whole plan. The next 2-4 weeks should run four parallel tracks:

1. bounded Sites 07/08 repair and re-audit, limited to trustworthy reusable primitive evidence;
2. selection and implementation planning for 2-3 app-backed owner-editable reference proofs;
3. early Gate 7 execution discovery for visitor action, owner/operator receipt, readiness and rollback;
4. founder-programme packaging as product-backed concierge delivery, with no self-serve or public-launch claim.
