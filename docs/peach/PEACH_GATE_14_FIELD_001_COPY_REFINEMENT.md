# PEACH Gate 14 Field 001 Copy Refinement

Date: 2026-07-31

## Goal

Use Gate 13 surrogate learnings to explain Field and Commons Return more plainly, reduce consent density where safe, and preserve PEACH's conceptual strength.

## Files edited

- `frontend-next/src/lib/peach/catalog.ts`
- `frontend-next/src/components/peach/PeachFieldView.tsx`
- `frontend-next/src/components/peach/PeachContributionForm.tsx`

## Catalog changes

- Changed phase from `Gate 10 internal pilot rehearsal foundation` to `Private internal pilot preparation`.
- Rewrote Field 001 short description to define a Field as a bounded cultural inquiry.
- Rewrote `reasonForNow` to remove migration-era wording and clarify that a consented work may later emerge.
- Rewrote Yield description to state no Yield is public in the private pilot.
- Rewrote Commons Return explanation as: the approved work, method, or learning that comes back to the community after consent and steward review.
- Reworded the Commons placeholder to explain the return path without publishing participant material.
- Reworded the first vessel access copy to avoid implying public publication during the pilot.

## Field view changes

Added a compact three-part explanation panel:

- Field: a bounded cultural inquiry opened by a Seed and stewarded toward possible shared work.
- Yield: a later work made only from reviewed material with the right consent.
- Commons Return: the approved work, method, or learning that comes back to the community after consent and steward review.

## Contribution form changes

- Replaced old `Gate 9` wording with current `private pilot` wording.
- Clarified that submissions are trusted-adult, non-sensitive, private, steward-reviewed, and never public from the form.
- Clarified that possible later Yield use requires steward review and a later consent check before public use.
- Kept sensitive/youth rejection explicit.

## What did not change

- No behavior changed.
- No public contribution display was enabled.
- No payment behavior was added.
- No upload behavior was added.
- No youth/sensitive collection was enabled.
- No public Commons/Yield release was added.
- PEACH was not reduced to book club, bookstore, ecommerce, events, feed, or subscription language.
