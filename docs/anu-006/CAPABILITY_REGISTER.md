## How to read status

- **Implemented** means the selected source contains a route or service.
- **Locally checked** means a named test or build ran against that source or its direct ancestor with synthetic/in-memory data.
- **Hosted reachable** means a public, unauthenticated HTTP request reached a route on the stated host. It does not prove its database schema, signed-in state, tenant isolation, writes, reviewer decision or notification delivery.
- **Journey proven** requires a dated, permissioned end-to-end record with a real selected host/database, named roles, persisted before/after state and rollback. **Human accepted** is a separate product/release decision.
- **Data source** distinguishes stored operational records, generated records, fixture/mock, stub and manual work. An HTTP 200 does not change a fixture into a live external source.

The owner column names an accountable **role**, not an assigned person. A named owner and last verification should be added by that role at release review.
